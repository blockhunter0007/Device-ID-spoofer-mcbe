# Device ID Spoofer

Simple Python tool for changing the Device ID of Minecraft for Windows.

## Features

* Find Minecraft automatically
* View current Device ID
* Randomize Device ID
* Apply a custom Device ID
* Reset to the original ID

## Requirements

* Windows
* Python 3.9+
* Minecraft for Windows

Install dependencies:

```bash
pip install customtkinter pymem
```

## Usage

Start Minecraft, then run:

```bash
python main.py
```

Use **Randomize**, **Apply**, or **Reset** from the GUI.
